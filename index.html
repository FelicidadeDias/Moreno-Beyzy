Como faço uma marcação?

Escolha o serviço, indique a data e hora e envie a mensagem pelo WhatsApp. Aguarde uma resposta para confirmar disponibilidade.

Os preços são definitivos?

Não. São valores fictícios para demonstrar o website e deverão ser substituídos pela tabela real do salão.

A hora fica reservada automaticamente?

Não. Este modelo não verifica uma agenda em tempo real. A marcação só fica confirmada após resposta do salão.

As fotografias são do Moreno Beyzy?

Não. São imagens ilustrativas de banco de imagens, que devem ser substituídas por fotografias autorizadas na versão final.
