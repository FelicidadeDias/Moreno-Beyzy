# Moreno Beyzy — Beleza & Estética

Website demonstrativo responsivo para salão de beleza, feito com HTML, CSS e JavaScript puros, pronto para GitHub Pages.

## Publicação
1. Confirme que `index.html` está na raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch `main` e a pasta `/(root)), e guarde.
5. Aguarde o GitHub Pages publicar. Endereço previsto: https://felicidadedias.github.io/Moreno-Beyzy/

## Incluído
- Design responsivo para telemóvel, tablet e computador.
- Serviços de cabelo, unhas, pés, rosto, maquilhagem, sobrancelhas, pestanas e depilação.
- Pacotes e preços fictícios em kwanzas.
- Galeria com fotografias ilustrativas externas do Unsplash.
- Formulário de pedido de marcação que prepara mensagem para WhatsApp.
- Botões de contacto, menu móvel, perguntas frequentes e avisos de demonstração.

## Antes de usar como site oficial
Substitua/valide todos os contactos, localização, horário, serviços, preços e condições. Substitua as fotografias por imagens autorizadas do salão e os testemunhos fictícios por comentários reais autorizados. O formulário não guarda dados nem confirma automaticamente reservas: abre o WhatsApp para a pessoa rever e enviar a mensagem. A disponibilidade deve ser confirmada manualmente pelo salão.

As imagens externas são servidas pelo Unsplash; confirme licenças e adequação para uso comercial antes da publicação final.
